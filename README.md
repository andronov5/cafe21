# Café 21 Express

A responsive café redesign built for a sales presentation. Uses the business's real photography, menu prices and contact details from cafe21express.com. The original repository contained only a README; all photos were retrieved from the official website.

## Development

- Node.js 22+
- `pnpm install`
- `pnpm dev`
- `pnpm build`

Built with React, TypeScript, Vinext and accessible Radix UI primitives. Fonts and images are hosted locally.

## Features

Responsive navigation; breakfast/lunch tabs; expandable lunch menu and food cards; real catering phone links; Google Maps directions; FAQ accordion; reduced-motion support.

Image provenance: `public/images/sources.json`.

Menu prices may change. Operating days were not established by the official website, so only meal service times are displayed. Ordering links lead to the existing official menus, and phone CTAs use the café's actual number. No simulated checkout or unconnected contact form. Search indexing is disabled for this demo.
